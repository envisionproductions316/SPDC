## 🌐 Live Site
Hosted via GitHub Pages: [https://envisionproductions316.github.io/SPDC](https://envisionproductions316.github.io/SPDC)

## ✨ Features
- Full church website with member portal
- Admin control panel (`admin@spdc.org` / `admin`)
- Member signup with admin approval workflow
- Prayer wall, events RSVP, sermon library
- Email campaign system with 6 templates
- Visual Flyer Builder with download
- Image library with drag & drop upload
- 16 color themes + 6 hero page layouts
- Mobile PWA (Add to Home Screen)
- AI site assistant

## 📁 Files
- `index.html` — Complete self-contained website (open in any browser)

## 🚀 Usage
Open `index.html` directly in any browser — no server required.
All images, fonts, and code are embedded in the single file.
