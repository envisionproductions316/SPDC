## Features
- Full church website with member portal
- Admin control panel for content, members, and settings
- Member signup with admin approval workflow
- Prayer wall, events RSVP, sermon library
- Email campaign composer with templates
- Visual Flyer Builder with download
- Image library with drag & drop upload
- Color themes and hero page layouts
- Mobile PWA (Add to Home Screen)
- AI site assistant

## Files
- `index.html` — Complete self-contained website
- `CNAME` — Custom domain (`spdc.church`)

## Usage
Open `index.html` locally, or visit the live domain after GitHub Pages deploys.
Admin can sign in from Member Login, then manage content from the Admin panel.
